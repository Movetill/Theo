# 数制与编码 · Teaching Guide

学习路径：权值与基数 → 进制转换（整数和小数要分开） → 定点数范围/溢出 → 原码/反码/补码 → BCD/Gray/奇偶校验/常用编码。逐位记录转换步骤。

实践：把 `-5` 分别写成 8 位原码、反码和补码；调用 `theo_signed_encode` 验证。演示二进制 `11111011` 既可能是无符号 251，也可能是 8 位补码 -5。

边界：`theo_radix_convert` 当前只处理整数，不处理二进制小数；`theo_signed_encode` 不表示负零（原码与反码仍需讲解负零编码）。BCD 以十进制各位分别编码，不等于把整个整数写成二进制。
