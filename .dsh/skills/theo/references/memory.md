# 存储器 · Teaching Guide

路径：bit/word/容量组织 → 地址线与数据线的计算 → ROM/PROM/EPROM/EEPROM/RAM → SRAM vs DRAM → 读写控制与片选 → 存储器容量扩展（字/位扩展） → 数据路径中的寄存器/存储器。

例：深度 2^10、字宽 8 的存储器共有 1024 字节（8192 bit），地址线至少 10 根，数据线 8 根。`theo_memory_trace` 只提供读/写事件的离散结果与地址/数据合法性校验，不做真实存储时序验证。

如果讲 SRAM/DRAM 时序或同步 RAM 读后写冲突，先明确时序协议，不得用现有简化模型冒充硬件结果。
