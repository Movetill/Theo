# 时序逻辑 · Teaching Guide

路径：锁存器和触发器区别 → D/JK/T → 时钟边沿、建立保持时间和复位 → 寄存器/移位寄存器/计数器 → 状态表/状态图 → Moore/Mealy FSM → 状态编码和简化。

教学顺序：明确 Q(t), 输入 X(t), Q(t+1) → 给特性方程或状态表 → 逐个边沿更新状态 → 构建状态轨迹和波形。

演示：JK 触发器 J=K=1 发生翻转；利用 `theo_flipflop_trace` 验证两个上升沿。`theo_fsm_trace` 以明确转移表验证控制器状态。

边界：工具提供离散沿结果，尚不包含 X/Z、异步复位、输入同步器、传播时延、时钟偏斜与建立保持时间判定。
