# 组合逻辑 · Teaching Guide

路径：基本门/复合门 → 逻辑表达式/真值表/卡诺图 → 译码器/编码器 → 数据选择器/分配器 → 半加器/全加器/加法器 → 比较器/ALU → 组合逻辑设计步骤。

核心流程：抽象输入输出 → 枚举真值表 → 逻辑化简 → 选择结构实现 → 功能验证 → 讨论延迟、扇出、竞争冒险。

演示：全加器 `sum=A xor B xor Cin`, `carry=AB+ACin+BCin`；可用 `theo_combinational` 的 `full_adder` 模式验证单组输入，或提交 1-bit gate netlist 生成表。

边界：不能把「最简 SOP」当作「面积/速度最优」，也不能把零延时真值表当作电路实际瞬态行为。
