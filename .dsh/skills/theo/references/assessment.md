# Learning and Verification Protocol

- 「知识讲解」：先给知识脉络、现实电路实例，再说明算法与电路的对应关系。
- 「题目解答」：列已知、求解目标、假设（位宽/编码/时序/复位等）、过程、验证、边界。
- 「提示模式」：每轮只给一个能推进的提示；学生提交中间步骤时验证并给具体反例。
- 「设计模式」：需求 → 输入输出 → 真值/状态表 → 电路/RTL → 测试向量 → 结果。
- 「实验模式」：明确是理论推导、零延迟求值、离散状态仿真、HDL 仿真还是综合；不能混用。
- 错误分类：概念错误、转换错误、漏掉真值表分支、组合/时序混淆、位宽/有符号错误、时钟/复位错误、RTL 语义错误。
- 工具结果只证明其模型范围内的性质；多元建模之间要做交叉验证，如 FSM trace vs Verilog 仿真。
